月之暗面又搞大新闻了。

2025年7月，他们发布了 Kimi K2——一个万亿参数的开源大模型。官方数据很漂亮：SWE-Bench 65.8 超过 GPT-4.1，LiveCodeBench 全模型最高，API 价格只有 Claude Sonnet 的七分之一。

听起来像是国产之光，Claude 平替终于来了？

**别急着下结论。**

## 先说好的

Kimi K2 确实有几个值得肯定的地方：

### 1. 真开源，而且是 MIT

不是那种「开源但不让商用」的假开源，K2 用的是 MIT 协议。虽然后来发现有些限制条款（月活和收入门槛），但至少比某些「开源」模型强多了。

### 2. MoE 架构做得不错

1T 总参数，32B 激活参数。这意味着推理成本可控，同时保持了大模型的能力。这是务实的工程选择。

### 3. Agent 能力确实强

K2 是专门为智能体场景设计的。工具调用、代码生成、多轮对话——这些 Agent 核心能力确实比之前的国产模型强一大截。

### 4. API 兼容性好

同时支持 OpenAI 和 Anthropic 的调用格式。对于想从 Claude 迁移的开发者来说，这省了不少事。

## 再说问题

但 K2 远没有官方宣传的那么美好。

### 1. 「便宜」是个伪命题

K2 的 API 价格确实低——输入 4 元/M tokens，输出 16 元/M tokens。但有人算过账：如果你是重度用户，K2 的实际花费不一定比 Claude Pro 订阅便宜。

更重要的是，**便宜的前提是能用**。很多场景下，K2 需要更多轮对话才能完成 Claude 一轮搞定的任务。省下的钱可能被更高的 token 消耗吃掉。

### 2. 工具集成稳定性堪忧

多个开发者反馈，K2 在与第三方工具集成时存在稳定性问题。对于生产环境的 Agent 系统来说，这是致命伤。

你可以接受一个模型偶尔犯傻，但不能接受它随机掉链子。

### 3. 本地部署？别想了

FP8 版本需要至少 16 块 GPU。普通开发者和小团队根本玩不起。所谓「开源」，对大多数人来说只是「开源但用不起」。

### 4. 基准测试的水分

K2 在 SWE-Bench 上跑出 65.8，但这个数字要打个问号。基准测试和实际使用之间的 gap，懂的都懂。

我实测下来，K2 在复杂推理任务上还是和 Claude Sonnet 有明显差距。那些「超越 GPT-4.1」的说法，听听就好。

## 我的结论

Kimi K2 是一个**不错的模型**，但不是**革命性的模型**。

它的定位很清晰：给那些被 Claude 断供吓怕了的中国开发者一个 Plan B。从这个角度看，它成功了。

但如果你期待它能完全替代 Claude 或 GPT-4——醒醒吧。

**该用 Claude 的场景还是用 Claude，K2 更适合作为备选或者成本敏感场景的补充。**

至于那些吹「国产之光」「吊打 OpenAI」的，我只能说：营销文案看看就好，别当真。

---

*最后说一句：月之暗面能做出 K2 这样的模型，本身已经很不容易了。只是希望国产 AI 公司能少一些浮夸的宣传，多一些务实的进步。*

*毕竟，用户要的不是「比肩 Claude」的 PPT，而是真正好用的产品。*
